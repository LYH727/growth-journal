# 成长手账

温和、分步的每日引导式复盘网页：回顾经历、发现有具体事例支撑的优点、理解困难，并把可改进的行为转成小行动。

## 运行

这是一个无后端依赖的静态网页。使用任意静态服务器托管本目录，然后访问 `index.html`。

记录和附件使用浏览器 IndexedDB 保存在当前设备，不会上传到服务器。不同域名、浏览器或设备之间的数据不互通。

## 文件

- `index.html`：页面结构
- `app.css`：界面样式
- `app.js`：四步复盘、草稿、材料、历史和行动回访逻辑

## 数据限制

单个附件最多 10 MiB，每条复盘附件合计最多 30 MiB。清除浏览器网站数据可能丢失记录。
